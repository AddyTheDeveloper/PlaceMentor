    2. Linked Lists (Linear Dynamics)

    TypeStructureKey Characteristic
    Singly Linked ListData → NextSimple. Uni-directional traversal.
    Doubly Linked ListPrev ↔ Data ↔ NextBi-directional traversal; occupies more pointer space.
    Circular Linked ListLast Node → First NodeNo NULL terminations; ideal for buffers and round-robin queues.

    Floyd's Cycle Finding (Fast & Slow Pointer Technique):

    1. Initialize two pointers, slow and fast, at the HEAD node.
    2. Advance slow by 1 step and fast by 2 steps.
    3. If slow == fast at any point, a cycle exists. If fast reaches NULL, there is no cycle.

    3. Stacks & Queues (Order Patterns)

    Stack (LIFO - Last In First Out)

    Applications: Recursive function calls, Undo/Redo operations, Expression parsing, Balanced parenthesis verification.

    Queue (FIFO - First In First Out)

    Applications: BFS traversal in graphs, print spoolers, CPU scheduling queues, messaging buffers.

    Circular Queue: Overcomes space wastage in basic linear queues where array slots before the FRONT index cannot be reused even after dequeue operations.

    4. Trees & Hierarchical Structures

    Binary Tree: A hierarchical tree structure where every node has at most two children.

    BST (Binary Search Tree): A binary tree with the property: Left Child < Parent < Right Child.

    Self-Balancing Trees (Interview Favorites)

    • AVL Trees: Strictly balanced BST where the height difference (balance factor) between left and right subtrees is at most 1. Uses rotations (LL, RR, LR, RL) to rebalance.
    • Red-Black Trees: Loosely balanced BST using node coloring rules (red/black). Offers faster insertions/deletions than AVL. Used in C++ STL std::map.

    BST vs AVL Search Complexity:
    - Normal BST Search: O(h), where h is height. Can degrade to O(n) for skewed trees.
    - AVL Search: Guaranteed O(log n) because height is strictly bounded.

    Trie (Prefix Tree)

    An advanced search tree used to store dynamic sets of strings. Nodes store characters rather than full keys. Ideal for prefix searches (e.g., auto-complete, dictionary lookups). Search/Insert complexity is O(L), where L is the string length.

    5. Graphs & Hashing

    Graph G = (V, E): A network of vertices (V) connected by edges (E). Can be directed/undirected and weighted/unweighted.

    Breadth-First Search (BFS)

    Queue-based level-order traversal. Finds the shortest path in unweighted graphs. Complexity: O(V + E).

    Depth-First Search (DFS)

    Stack/Recursion-based deep traversal. Used for cycle detection, topological sorting. Complexity: O(V + E).

    Hashing Conflict Resolution

    TechniqueDescription
    Chaining (Open Hashing)Maintains a linked list at each bucket. Avoids table limits but uses extra pointer memory.
    Open Addressing (Closed Hashing)Finds next available slot in-place using Linear Probing, Quadratic Probing, or Double Hashing.
    Disjoint Set Union (DSU) / Union-Find

    An algorithm to track elements partitioned into disjoint subsets. Optimized via two techniques:

    • Union by Rank: Always attaches the shorter tree under the root of the taller tree to minimize height.
    • Path Compression: Flattens the tree structure during find queries, pointing visited nodes directly to the root.

    Combined amortized complexity is nearly constant: O(α(n)) per operation.

    Consistent Hashing: Used in distributed databases and load balancers. Minimizes remapped keys when cache servers are added or removed (only K/n keys need to shift, compared to nearly all keys in standard modulo hashing).

    Placement FAQ: Data Structures

    1. Compare Array vs Linked List. Array has O(1) random access but fixed size. Linked List is dynamically sized but requires O(n) sequential traversal.
    2. How to detect a cycle in a Linked List? Use Floyd's cycle detection (Slow pointer moves 1 step, Fast pointer moves 2 steps; if they meet, there is a cycle).
    3. What is the worst-case complexity of a BST? O(n) when elements are inserted in sorted order, creating a skewed tree. AVL/Red-Black trees solve this by self-balancing.
    4. Explain Heap and its types. A complete binary tree that satisfies the heap property. In Max-Heaps, parents are ≥ children. In Min-Heaps, parents are ≤ children. Used for Priority Queues.
