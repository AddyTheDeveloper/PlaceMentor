    2. Pointers & Memory Management

    Pointer: A variable that stores the physical memory address of another variable.

    Dereferencing (*): Accessing the data at the address held by the pointer.

    Address-Of (&): Getting the memory address of a variable.

    Pointer Types (Placement Interview Highlights)

    • NULL Pointer: Points to nothing (address 0). Safe placeholder. int *p = nullptr;
    • Void Pointer: Generic pointer, can point to any data type. Needs typecasting to dereference.
    • Wild Pointer: Uninitialized pointer that points to a random memory address. Very dangerous.
    • Dangling Pointer: Points to a memory location that has already been freed/deleted.

    Visual Learning: C++ Memory Segmentation

    Stack (Local variables, function frames) ↑
    Heap (Dynamically allocated space via new/malloc) ↓
    Data Segment/BSS (Global & static variables)

    Advanced C++: Smart Pointers (Automatic Memory Management)

    Smart pointers ensure automated deallocation to prevent **Memory Leaks**.

    • std::unique_ptr: Exclusive ownership. Cannot be copied, only moved.
    • std::shared_ptr: Shared ownership via reference counting. Deallocates when count reaches 0.
    • std::weak_ptr: Non-owning observer reference to prevent cyclic dependencies.

    3. Parameter Passing Techniques

    Call by Value

    A copy is made. Original caller value is unaffected.

    void swap(int x, int y)

    Call by Reference (C++)

    Creates an alias. Direct modifications affect the original caller.

    void swap(int &x, int &y)

    Call by Address

    Memory address is passed. Needs pointer dereferencing inside the method.

    void swap(int *x, int *y)

    5. Runtime Polymorphism & V-Tables

    Virtual Function: Declared with keyword virtual in base class, overridden by derived class.

    Pure Virtual Function (Abstract Class): virtual void draw() = 0;. Class cannot be instantiated.

    How Runtime Polymorphism Works Under the Hood:
    1. V-Table (Virtual Table): Static array of function pointers generated for classes containing virtual functions.
    2. vptr (Virtual Table Pointer): A hidden pointer added to objects pointing to the class's V-Table.
    3. Resolution: The compiler resolves calls dynamically at runtime: obj -> vptr -> V-Table -> Function Address.

    Note: The presence of virtual functions increases the object size by the size of the vptr (usually 8 bytes on 64-bit systems).

    Virtual Inheritance & The Diamond Problem

    The Problem: Subclass inherits from two parents who share a common ancestor, causing duplication of the ancestor's data members.

    The Solution: Inherit using the virtual keyword. This tells the compiler to allocate only a single shared copy of the base ancestor class.

    class ParentA : virtual public Base { ... };
class ParentB : virtual public Base { ... };
class Child : public ParentA, public ParentB { ... };

    6. Exception Handling & Generic programming

    Exception Handling comparison

    C++ Exception Handling

    Uses try, catch, and throw. Does not have a finally block; relies on RAII (Resource Acquisition Is Initialization) and destructors for automated cleanup.

    Java Exception Handling

    Uses try, catch, finally, and throw/throws. Supports checked exceptions enforced at compile time.

    Templates (Generic Programming)

    Templates allow writing generic code where data types are parameterized.

    template <typename T>
T findMax(T a, T b) {
    return (a > b) ? a : b;
}

    Placement FAQ: Programming

    1. What is a Memory Leak? Occurs when program allocates memory in heap and fails to delete it before losing reference.
    2. Difference between Structure and Class? In C++, default access in structs is public, whereas in classes it is private.
    3. Explain the virtual destructor. A base class destructor must be virtual to ensure derived destructors are called when deleting derived objects via base pointers.
    4. What is a Friend Function? A non-member function granted access to a class's private/protected members.
